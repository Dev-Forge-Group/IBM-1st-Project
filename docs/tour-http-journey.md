# 실제 HTTP 투어 흐름과 신청 실패 복구

IBM-07은 투어 API를 실제 서버 요청으로 연결하고 신청 실패를 두 화면 모드에서 확인할 수 있게 한다. 생성 화면은 실패 메시지를 상태에 보관했지만 독립 페이지에는 표시하지 않았고 팝업에는 같은 메시지를 두 번 표시했다. 실패한 신청을 성공으로 이동시키거나 입력을 지우지 않고, 오류를 한 번 보여 준 뒤 사용자가 현재 선택으로 다시 신청할 수 있게 한다.

## HTTP 계약

`TourHttpJourneyIntegrationTest`는 `RANDOM_PORT` 서버와 실제 socket HTTP client, MySQL8.4·Flyway·JWT·보안 필터를 사용한다. 요청 사이에 커밋된 상태와 다시 조회한 가용 시간을 검사하며 MockMvc나 바깥 테스트 트랜잭션에 의존하지 않는다.

- 공개 건물·예약 가능 방·슬롯에서 받은 ID와 시간을 사용해 신청하고, 전화/PIN 조회 결과와 슬롯 소멸을 확인한다. 공개 투어 흐름은 무토큰·guest·user·tenant·admin 모두 같은 credential 계약을 따른다.
- 전화 중복·방 시간 충돌은 기존 409 코드다. 잘못된 PIN 취소는 기존 오류이며 상태를 변경하지 않는다. 정상·반복 취소는 이력을 보존하고 시간을 다시 사용할 수 있게 한다.
- 관리자 목록과 상태 변경은 무토큰 401, guest/user/tenant 403이며 admin이 처리한다. 다른 신청이 점유한 시간으로 복구하면 409와 두 예약의 상태를 보존한다. 시간이 비면 복구할 수 있고 완료 상태의 사용자 취소는 기존 오류다.
- 잘못된 날짜·숫자·enum 또는 누락된 필수 query parameter는 HTTP400 `COMMON_400`이다. `MethodArgumentTypeMismatchException`과 `MissingServletRequestParameterException`을 명시적으로 처리하며 원래 입력·예외 이름·내부 상세를 응답에 반사하지 않는다. 도메인 오류·JSON 검증·예상하지 못한 서버 예외의 기존 계약은 유지한다.

예약/PIN·전화 비교·V16 쓰기 잠금·관리자 허용 상태를 새로 정의하지 않는다. 실제 화면의 요청 문맥은 [생성 폼 계약](tour-reservation-form.md)을 따른다. 재시도는 사용자 동작이며 생성 POST를 자동 재전송하거나 멱등성이 있다고 주장하지 않는다.

## 화면과 브라우저 검증

React 회귀는 독립 페이지와 팝업에서 충돌·서버 실패 표시가 한 번 나타나는지, 입력과 현재 선택을 보존하는지, 실패 뒤 성공 이동/callback 없이 명시적으로 재시도할 수 있는지 검사한다. 이 회귀의 API 응답은 mock이다.

로컬 Chromium 검증은 별도의 합성 Vite 설정(`envDir:false`)으로 제품 화면을 실행하고 임시 MySQL의 실제 backend에 `/api`를 연결한다. 외부 사이트 요청은 차단하며 API 응답을 mock하지 않는다. 빈 시간을 화면에서 선택한 뒤 다른 요청으로 점유하여 실제 409를 만들고, 오류 표시·점유 해제 뒤 재시도·조회·취소를 확인한다. 이 로컬 guest 여정을 모든 역할의 브라우저 여정으로 확대하지 않는다.

브라우저 준비를 위해 HTTP suite에는 선택적인 `UNIPLACE_TOUR_BROWSER_READY` 파일 경로를 지원한다. 지정하면 모든 HTTP 회귀 뒤 별도 합성 건물/방의 주소·ID·날짜만 새 ready JSON으로 쓰고 최대 120초 동안 `.done` 파일의 `passed`를 기다린다. 토큰·PIN을 ready 파일에 넣지 않는다. 브라우저 실패·시간 초과는 suite 실패이며, 변수를 지정하지 않는 기본 CI는 실제 HTTP 회귀만 실행하고 브라우저 검증 완료를 주장하지 않는다. 추가 skip 테스트로 통과를 만들지 않는다.

[필수 CI](ci.md)는 HTTP suite의 누락·0개·skip을 실패로 처리한다. 로컬 브라우저의 실행 결과와 캡처, 실제 API 회귀·전체 FE/BE·원격 Actions·운영 배포는 각각의 증거로 구분한다. 운영 데이터와 외부 AI·메일·OAuth·결제는 이 검사에서 사용하지 않는다.
